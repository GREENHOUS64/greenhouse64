Политика конфиденциальности

Эта страница описывает обработку данных при обращении через сайт. Перед постоянным сбором заявок оператору необходимо заполнить юридические сведения, отмеченные ниже.

Требует заполнения перед полноценным запуском: полное наименование оператора (ИП/ООО или ФИО), ИНН, адрес и срок хранения обращений. Эти сведения владелец проекта ещё не предоставил.

Кто обрабатывает данные

Оператор сайта — GREENHOUSE. Контакт по вопросам обработки данных: antoniykushev7@gmail.com. Полное юридическое наименование и реквизиты оператора должны быть добавлены владельцем сайта.

Какие данные указываются

Форма может содержать имя, телефон и текст обращения. Не указывайте в сообщении сведения, не нужные для ответа на вопрос.

Для чего нужны данные

Данные используются только для ответа на обращение, уточнения задачи и связи по запросу пользователя.

Как работает форма сейчас

До подключения Supabase сайт открывает почтовый черновик, и обращение поступает оператору только после отправки письма самим пользователем. После подключения формы будут передавать имя, телефон, текст обращения и время согласия в базу Supabase для ответа на запрос. Для ограничения автоматических отправок сервер хранит хеш IP-адреса с часовым счётчиком без исходного адреса.

Аналитика

Google Analytics 4 загружается только после явного согласия посетителя. При отказе скрипт аналитики не загружается. Если GA4 будет активирована, оператор должен указать в этой политике срок хранения данных, настройки ресурса и актуальную информацию о сервисе.

Обращения по поводу данных

Чтобы запросить уточнение или удаление данных, напишите на antoniykushev7@gmail.com и укажите способ связи, которым пользовались.
